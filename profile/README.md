Capydocs is a brand new local document manager, markdown and textpack editor, diagram editor, trello-like kanban app and more for Windows and Macos.
Manage your projects, write down diaries, manage your knowledge-base and keep your files locally in open formats. Like Windows Explorer but editing stuff in-place, like Notion but private and local, like Obsidian but more visual.
